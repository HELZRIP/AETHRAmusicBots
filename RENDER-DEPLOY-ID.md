# AETHRA MUSIC - Render Free test deployment

This Render variant runs the Discord bot and Lavalink in one Docker web service. It is for testing/hobby use, not guaranteed 24/7. Render Free has 512 MB RAM, spins down after 15 minutes without inbound traffic, and has an ephemeral filesystem. Queue/state data may be lost on restart, spin-down, or redeploy.

## Deploy
1. Upload the contents of this folder to a GitHub repository (not the ZIP file itself).
2. In Render, choose New > Blueprint and connect that repository.
3. Render reads `render.yaml`. Choose the free plan.
4. Enter `DISCORD_TOKEN` and `CLIENT_ID` when prompted. `LAVALINK_PASSWORD` and `DASHBOARD_PASSWORD` are generated by Render.
5. Deploy and inspect logs. Wait for `Lavalink siap` and `AETHRA MUSIC online`.
6. Open the service's `onrender.com` URL. Dashboard login uses the generated `DASHBOARD_PASSWORD` environment variable.

Do not share bot token, dashboard password, or Lavalink password.
